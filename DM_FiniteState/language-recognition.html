Language Recognition

จากการตรวจ string ทีละตัว เราจะขยับมามองว่าเครื่อง M ยอมรับ strings ใดบ้าง และ strings เหล่านั้นรวมกันเป็น language ของเครื่องได้อย่างไร

ทดสอบ x ∈ L(M) ทบทวนนิยาม L(M)
String x→ Read every symbol→ End state→ Compare with F→ Membership result
นิยามสำคัญมาก

เมื่อไร string จึงถูก recognized หรือ accepted?

ให้ x เป็น input string เมื่อเครื่องอ่าน x จนครบแล้ว ถ้า x พาเครื่องจาก start state s0 ไปยัง state ที่อยู่ในเซตของ final states F เราจะกล่าวว่า string x ถูก recognized หรือ accepted

เขียนเป็นสัญลักษณ์ได้ว่า f(s0, x) ∈ F

f(s0, x) คือ state ที่เครื่องไปถึงหลังเริ่มจาก s0 และอ่าน x จนครบ

การตัดสิน accepted หรือ rejected ดูจาก state หลังอ่าน input จบ ไม่ได้ตัดสินจาก state ที่ผ่านระหว่างทาง
Language ของเครื่อง

L(M) หมายถึงอะไร?

L(M) อ่านว่า language recognized by machine M หมายถึง เซตของ strings ทุกตัวที่เครื่อง M ยอมรับ

L(M) = { x | f(s0, x) ∈ F } ดังนั้น x ∈ L(M) ก็ต่อเมื่อเครื่อง M accepted string x

Key Idea

L(M) คือทั้งภาษา ไม่ใช่ string เดี่ยว

เมื่อเราเขียน x ∈ L(M) หมายถึง string x เป็นหนึ่งใน strings ที่ machine M accepted ถ้า machine สองตัว accepted string ชุดเดียวกันทั้งหมด ก็ถือว่า recognize language เดียวกัน
