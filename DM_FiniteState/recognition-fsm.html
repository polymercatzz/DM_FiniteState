วิธีเล่น Substring Recognizer

ใช้เวลาประมาณ 1 นาที

  1. 1

    สร้าง Binary string โดยพิมพ์เองหรือกดปุ่ม 0 และ 1 ตามลำดับที่ต้องการ

  2. 2

    ทายผลล่วงหน้าว่า string นี้มี substring 111 ที่เรียงติดกันหรือไม่ แล้วเลือก Recognized หรือ Not recognized

  3. 3

    กด Run หนึ่งครั้ง ระบบจะเลื่อนไปยังผลลัพธ์และเฉลย state กับ output ทีละ step โดยอัตโนมัติ

  4. 4

    เมื่อเล่นจบ ใช้ปุ่ม ย้อนกลับ และ ถัดไป เพื่อไล่ดูแต่ละ step อีกครั้ง

Sort by Last Output Bit

เลือกกลุ่มให้แต่ละ string แล้วระบบจะเฉลยโดยย้ำว่า recognized ต้องดูที่ last output bit

เลือกใหม่ได้จนกว่าจะเข้าใจกฎ

Key Idea

ทำไม 11011 ไม่ recognized

เพราะโจทย์ต้องการ 1 ติดต่อกันสามตัว ไม่ใช่นับจำนวน 1 ทั้งหมดใน string ดังนั้น 11011 มี 11 สองชุด แต่ไม่มี substring 111 และ last output bit จึงเป็น 0

State memory
  • s0ยังไม่มี suffix ที่ช่วยให้ครบ 111
  • s1suffix ล่าสุดคือ 1
  • s2suffix ล่าสุดคือ 11
  • s3พบ 111 แล้ว และจำถาวร
