Finite-State Machines with Output

เรียนรู้ state, input และ output ผ่านตู้ขายขนมจำลอง อ่านนิยามให้เห็นภาพ แล้วทดลองกด input เพื่อสังเกต transition ทีละขั้น

เริ่มทดลองกับตู้ขายขนม อ่านพื้นฐานก่อน
Definition

FSM คืออะไร

Finite-State Machine หรือ FSM คือแบบจำลองของระบบที่มีจำนวน state จำกัด ระบบเริ่มจาก start state แล้วรับ input ทีละตัว ทุกครั้งที่รับ input ระบบจะเปลี่ยน state และอาจสร้าง output ออกมา

M = (S, I, O, f, g, s0)

Reading the Table

State table อ่านอย่างไร

แต่ละช่องของตารางอยู่ในรูป next state / output เช่น s3 + input 10 → s4 / ทอน 5 บาท หมายความว่าเมื่อสะสมเงิน 15 บาทแล้วหยอด 10 บาท เครื่องจะไปที่ state พร้อมเลือกสินค้าและทอน 5 บาท
