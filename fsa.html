FSM with No Output / FSA

Finite-State Machine แบบไม่มี Output เรียกว่า Finite-State Automaton (FSA) เครื่องจะอ่าน input และตัดสินผลจาก state สุดท้ายหลังอ่านครบทั้ง string

เริ่มตามหา End State เปรียบเทียบ FSM กับ FSA
FSM with Output→ตัดสินจาก Output FSA→ตัดสินจาก End State ∈ F
Definition Machine Definition

Finite-State Automaton

กำหนด FSA ด้วย 5-tuple โดยไม่มี output alphabet O และ output function g

M = (S, I, f, s0, F)

ไม่มี O และ g — FSA สนใจเส้นทางและ end state เท่านั้น

S
Statesเซตของสถานะทั้งหมดที่เครื่องสามารถอยู่ได้
I
Input alphabetเซตของสัญลักษณ์ input ที่เครื่องอ่านได้
f
Transition functionกำหนด state ถัดไปจาก state ปัจจุบันและ input: f: S × I → S
s0
Start stateสถานะเริ่มต้นก่อนเครื่องอ่าน input ตัวแรก
F
Set of final statesเซตของสถานะยอมรับ ถ้า end state อยู่ใน F ผลคือ Accepted

บทนี้ตัดสินจาก end state

FSM with output ในบทก่อนใช้ output ที่เครื่องผลิตออกมา แต่ FSA ไม่มีการผลิตผลระหว่างทาง จึงตัดสินหลังอ่าน input จบว่า end state อยู่ใน set F หรือไม่

M = (S, I, f, s0, F) สิ่งที่หายไปคือ output alphabet O และ output function g End state ∈ F → Accepted; End state ∉ F → Rejected ในโจทย์ของหน้านี้ F = S
