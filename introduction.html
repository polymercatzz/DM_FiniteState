Lesson 01

Introduction to Models of Computation

แบบจำลองการคำนวณช่วยให้เราอธิบายระบบอย่างเป็นขั้นตอน เห็นว่าอะไรคือ input, state, rule, output และผลลัพธ์สุดท้ายของการทำงาน

  • 01อธิบายหน้าที่ของ computation model
  • 02แยก Input, State, Rule และ Output ได้
  • 03อธิบายว่า FSM เหมาะกับระบบแบบใด
Core Idea

Modeling Computation คืออะไร

Modeling Computation คือการสร้างแบบจำลองเพื่ออธิบายการคำนวณอย่างเป็นระบบ แทนที่จะมองคอมพิวเตอร์เป็นกล่องดำ เราแยกการทำงานออกเป็นส่วนประกอบ เช่น input, state, rule, output และ final result

คำถามที่แบบจำลองช่วยตอบ

  • งานนี้สามารถทำด้วยคอมพิวเตอร์ได้หรือไม่
  • ถ้าทำได้ ต้องออกแบบขั้นตอนการทำงานอย่างไร
  • ต้องจำข้อมูลมากแค่ไหนระหว่างประมวลผล
  • ผลลัพธ์ถูกตัดสินจากอะไร
Model Overview

ตัวอย่างแบบจำลองการคำนวณ

ตารางเปรียบเทียบแบบจำลองการคำนวณ
Model ใช้อธิบายอะไร
Grammars กฎการสร้างภาษา หรือรูปแบบของ string ที่ถูกต้อง
Finite-State Machines ระบบที่มี state จำกัด และเปลี่ยน state ตาม input
Turing Machines แบบจำลองทั่วไปของการคำนวณที่ทรงพลังกว่า FSM
Why FSM Matters

ทำไม FSM ถึงสำคัญ

Finite-State Machine เหมาะกับระบบที่มีจำนวนสถานะจำกัด แนวคิดหลักคือระบบไม่จำเป็นต้องจำทุกอย่างในอดีต แต่จำเฉพาะสถานะปัจจุบันที่เพียงพอต่อการตัดสินใจขั้นถัดไป

  • ตู้ขายสินค้า
  • ประตูอัตโนมัติ
  • ระบบตรวจ pattern ในข้อความ
  • network protocol
  • spell checking และ grammar checking
  • parser บางส่วนในภาษา XML หรือ HTML
